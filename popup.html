DropICS

Drag & drop .ics for Google Calendar

Used for bottom-half drop and right-click .ics link imports.

Ways to import
Top half Drop .ics/.csv to preview events & pick a calendar in-page
Bottom half Drop to auto-import to target calendar & jump to event date
Toolbar Click for Import & Export · Alt+Click to pick files directly
Alt+I Pick one or multiple .ics/.csv files for batch import
Right-click Right-click any web .ics link to import directly in background
